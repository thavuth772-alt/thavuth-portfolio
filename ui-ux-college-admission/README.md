# College Admission Portal – UI/UX Project

A responsive **College Admission Portal UI/UX project** created as a front-end practice project.

## Project Goal
Design a simple and student-friendly admission experience that guides users through:

- Personal Information
- Academic Details
- Document Submission
- Review & Submission
- Application Progress Tracking

## UI/UX Features

- Clean and modern interface
- Guided multi-step application workflow
- Progress indicator
- Responsive layout for desktop, tablet and mobile
- Form validation
- Clear status and feedback indicators
- Student-focused navigation

## Technologies

- HTML5
- CSS3
- JavaScript
