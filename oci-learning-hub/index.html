☁️ Cloud Computing Basics

Cloud computing means using computing resources over the Internet instead of purchasing and maintaining physical infrastructure yourself.

What is Cloud Computing?

Instead of buying a physical server, you rent computing resources from a cloud provider.

Simple Example
Your laptop → Physical computer
OCI Compute Instance → Cloud computer

Cloud Service Models

IaaS

Infrastructure as a Service

Example: OCI Compute

PaaS

Platform as a Service

Example: Autonomous Database

SaaS

Software as a Service

Example: Cloud applications

🌍 OCI Regions & Availability Domains

OCI infrastructure is organized into Regions, Availability Domains and Fault Domains.

🌍

Region

Geographical area containing OCI infrastructure.

🏢

Availability Domain

Isolated data center group inside an OCI Region.

🏗️

Fault Domain

Grouping of hardware designed to reduce impact of hardware failures.

🌐 OCI Networking

🌐

📡

🌍

🔒

NAT Gateway

🛣️
